## Penerjemahan visual

| Pada gambar | Implementasi |
| --- | --- |
| Kanvas putih-biru dengan sudut besar | Shell halaman membulat di atas latar biru muda (`#C1E8FF`) |
| Tipografi hitam besar, aksen biru | Headline teknologi dan manfaat penggunaan sehari-hari |
| Panel kaca bertumpuk diagonal | Ilustrasi smartphone/tablet berperspektif dengan panel transparan |
| Tiga kartu fitur | Bantuan mengenali kebutuhan, membandingkan, dan mengonfirmasi detail |
| Logo ekosistem | Penyebutan merek sebagai contoh kategori, tanpa klaim kemitraan resmi |
| Bagian perangkat di tangan | Komposisi smartphone dan kartu informasi ringan pada profil toko |
| CTA akhir | Konsultasi perangkat, informasi lokasi dan jam toko |

Tanpa gradient ungu, emoji, pembuka generik, atau angka bisnis palsu. Ilustrasi perangkat menggunakan CSS dan bukan replika model merek tertentu. Animasi masuk/hover menghormati reduced motion.

## Hierarki konten

1. Hero: pengenalan toko dan ajakan menjelajahi produk.
2. Pendekatan layanan: membantu pelanggan menentukan pilihan.
3. Katalog: filter, pencarian, detail, dan tanya produk.
4. Tentang toko: company profile dan pendekatan pelayanan.
5. FAQ: harga, stok, status merek, garansi, cara pembelian.
6. Kontak: konsultasi, alamat, jam operasional.

Konten yang belum diberikan ditandai belum tersedia; tidak mengarang riwayat toko, nomor kontak, atau alamat.
